- "Volatilidade Extrema" exige curadoria de dados históricos — subestimado no
  PRD; fica para R1.1.

### Sally 🎨
- Risco do R1.0: jogador **não perceber** que declarou um call. Precisa de
  estado visual explícito ("🎯 Called shot: +5% @ 10x → 12 💎 se bater").
- O **momento do acerto precisa de celebração** (diamantes voando ao contador,
  streak visível) — isso é a feature, não polish.
- **Desacordo parcial registrado:** shell mobile não deveria ser adiado — a
  visão é mobile-first e cada semana no desktop treina o usuário errado.

### Mary 📊
- Payouts do PRD são chute até haver dados — **instrumentar taxa de acerto por
  dificuldade desde o dia 1** (alvo 30–45%).
- **Guards anti-farm na v1** (cooldown, cap por run): economia quebrada em
  produção não se conserta.
- Called shot lê fills, não altera engine — risco médio-baixo.

### Paige 📚

  2. **Alvo e SL no mesmo candle** — regra precisa existir antes do código;
  3. Liquidação antes do alvo → call perdido + streak zerado;
  4. Payout com streak.
- E2E de run completa. Baseline 679 é sagrado.
